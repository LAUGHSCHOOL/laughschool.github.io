// Server software

PaperMC 1.21.11

Paper is the Minecraft server jar under Laugh School SMP. Target game version: 1.21.11.

SoftwarePaper
Version1.21.11
Java21+
HostRaspberry Pi 5 8GB

Install

  1. Install Java 21 (aarch64).
  2. Download the Paper 1.21.11 build from papermc.io.
  3. Create a server folder (example ~/laughschool-smp/).
  4. Place paper-1.21.11-*.jar there and create a start script.
  5. Accept eula.txt, configure server.properties, restart.

Example start script

#!/usr/bin/env bash
cd "$(dirname "$0")"
java -Xms2G -Xmx5G -jar paper-1.21.11.jar --nogui

spawn-protection0 if WorldGuard handles spawn

paper-global.yml / paper-world defaults

  • Prefer Paper’s async chunk IO defaults unless profiling says otherwise
  • Disable unused anti-xray modes that burn CPU if you do not need them
  • Watch /spark or Paper timings after plugin changes

Plugin folder rules

  • Only Paper/Bukkit jars in plugins/
  • Never drop Fabric/Forge mod jars into plugins/
  • Prefer full restarts over /reload

Update policy

  1. Read Paper changelogs + plugin compatibility for the new build
  2. Backup world*, plugins/, and configs
  3. Update Paper jar on a test copy when possible
  4. Update Via* stack together when bumping game versions
