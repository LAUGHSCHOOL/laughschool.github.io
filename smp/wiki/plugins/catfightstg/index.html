CatFightSTG

Paper port of Chesy’s Cat Fighting mod: cats quarrel visually, and can be flattened with shovels or minecarts. Vanilla clients supported.

PluginCatFightSTG
Jar / versioncatfighting-paper-1.21.11-1.2.1
ServerPaper 1.21.11
HostPi 5 8GB

Requirements

  • Paper 1.21.11 (Spigot/Folia not supported)
  • Java 21+
  • Use the Paper jar only — never the Fabric/Forge/NeoForge mod jar in plugins/

Install

  1. Install catfighting-paper-1.21.11-1.2.1.jar
  2. Remove any catfighting-fabric/forge/neoforge jars from plugins/ and remapped folders
  3. Restart, edit plugins/CatFighting/config.yml, then /catfighting reload

Features we rely on

  • Automatic nearby cat fights (no real cat-vs-cat damage)
  • Sitting cats skipped when configured
  • Flatten via shovel or moving minecart; unflatten via shovel / sneak empty-hand / command

Commands

CommandPermissionDescription
/catfighting reloadcatfighting.adminReload config
/catfighting flattencatfighting.adminFlatten looked-at cat
/catfighting unflattencatfighting.adminRestore looked-at cat

Aliases: /catfight, /cf. Shovel/minecart flatten needs no permission.
