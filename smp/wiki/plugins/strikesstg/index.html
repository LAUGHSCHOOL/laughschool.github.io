StrikesSTG

Paper chat filter that strikes players for configured swear words in chat, signs, and books — with thresholds up to bans.

PluginStrikesSTG
Jar / version1.0.0
ServerPaper 1.21.11
HostPi 5 8GB

Install

  1. Install StrikesSTG-1.0.0.jar
  2. Edit config.yml banned words + ban thresholds
  3. Restart (avoid /reload)

Behaviour

  • Whole-word matches only
  • 1 strike per matched word; censors to red ***
  • On-screen title: You got N strike(s)!
  • Persists to strikes.yml

Commands

CommandPermissionDescription
/strikesstrikesstg.strikesView own strikes
/strikes strikesstg.strikes.othersView others
/strikes reset strikesstg.resetClear strikes

Config example

banned-words:
  - "..."
ban-thresholds:
  - strikes: 3
    duration: 1d
  - strikes: 5
    duration: forever
